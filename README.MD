# AI VERIFY - News Verification Model

A DistilBERT-based fake news detection model built using Hugging Face Transformers.

## Features

- Fake/Real news prediction
- Confidence score
- DistilBERT fine-tuned model
- Flask ready

## Installation

```bash
pip install -r requirements.txt
```

## Clone

```bash
git clone https://github.com/Sydmoosa7/AI-VERIFY-News-Model.git
```

## Run

```bash
python run.py
```

## Model

The model is stored in:

saved_models/text_model/
